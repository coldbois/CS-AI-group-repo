# Section 10: Introduction to Software

## 1. What is software?

**Software** is the collection of programs, data, and instructions that tell computer hardware what to do. **Hardware** is the physical equipment—such as a processor, keyboard, screen, or memory chip—while software gives that equipment useful tasks to perform.

One analogy is a piano and sheet music. The piano is the hardware; the sheet music is like software because it describes what the instrument should play.

Software is more than the code alone. It can include:

- **Code:** the instructions that make a program work.
- **Data:** information the program reads, creates, or changes.
- **Documentation:** explanations that help people install, use, or maintain the software.
- **User interface (UI):** the screens, menus, buttons, and other controls people use to interact with it.

## 2. Main categories of software

| Category | What it does | Examples |
|---|---|---|
| **System software** | Helps manage and control the computer and its hardware. | Operating systems, system utilities, and compilers. |
| **Application software** | Helps people perform tasks. | Web applications, word processors such as Word, games, and browsers such as Chrome. |
| **Middleware** | Helps different applications or systems communicate or work together. | Database services, APIs, and software connectors. |

A **web browser** such as Chrome is application software because its main purpose is to help a person access and use websites. It is not classified as system software simply because it runs on the computer. An **API** (application programming interface) defines a way for software components to request services or exchange information.

## 3. A brief history of software

- **19th century — Ada Lovelace and Charles Babbage:** Babbage designed the Analytical Engine, a proposed mechanical general-purpose computing machine. Ada Lovelace published an algorithm intended for it, to calculate Bernoulli numbers. She is often described as the first computer programmer because of this work.
- **1936 — Alan Turing:** Turing described the abstract model now called the Turing machine. It helped formalize what it means for a machine to carry out a computation by following instructions. Turing's work came about a century after Babbage and Lovelace; he did not work with Babbage on the Analytical Engine.
- **Early electronic computers:** Programmers sometimes had to express instructions in machine code, a low-level representation of instructions using numeric patterns that computers could execute. At the most basic level, digital hardware represents information with binary values, commonly written as `0` and `1`.
- **1950s–1960s — high-level languages:** Languages such as **FORTRAN**, designed especially for scientific and engineering calculations, and **COBOL**, designed for business data processing and administration, made programs more readable and productive to write. They were important in the development of the software industry. FORTRAN predates Python by several decades.

## 4. Why middleware matters

Different systems may use different programs, databases, or interfaces. Middleware provides a layer that helps them communicate rather than requiring every pair of systems to be built specifically for each other. For example, an application may use a database service through an API instead of communicating with the database's internal implementation directly.

## Key takeaways

- Hardware is the physical computer; software provides instructions and behavior.
- Software includes code, data, documentation, and often a user interface.
- System software manages the computer, application software helps users perform tasks, and middleware connects software components.
- Lovelace's work on Babbage's proposed machine, Turing's theoretical model, and early high-level languages are important milestones in software history.
