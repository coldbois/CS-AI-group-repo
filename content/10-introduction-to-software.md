# Section 10 — Introduction to Software

Software is the programs, data, and instructions that tell a computer what to do. Hardware is the physical machine; software gives it tasks. Think of a piano and sheet music: the piano is the hardware, and the music gives it directions.

Software is more than code. It also includes the data a program uses, documentation that explains it, and the interface people use to control it.

## Three common kinds of software

**System software** manages the computer itself. Operating systems, utilities, and compilers are examples.

**Application software** helps people do specific things, such as browsing the web, writing documents, or playing games. Chrome is an application because it serves the user rather than managing the computer's hardware.

**Middleware** helps different programs or services communicate. Databases, APIs, and connectors can play this role.

## A short history

In the 1800s, Ada Lovelace wrote an algorithm intended for Charles Babbage's proposed Analytical Engine. She is often described as the first computer programmer. In 1936, Alan Turing described an abstract machine that helped explain computation. Early computers were programmed close to machine code, using binary instructions. By the 1950s and 1960s, languages such as FORTRAN for scientific work and COBOL for business made programming more practical.

Babbage designed the Analytical Engine, Lovelace wrote instructions for it, and Turing's work came later and was theoretical. They made different contributions to computing.

The main point is that software has several parts and categories, and those parts work together to make a computer useful.
