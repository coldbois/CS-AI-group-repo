## 📄 The Project
The project module we have chosen is Software and Symbolic AI. In this project, DanD's Disciples will teach Software & Symbolic AI to complete beginners through one shared set of Markdown content. The Markdown content consists of a  Study Guide with a Test Bank, PPT Slides, Video Tutorials and a live mini lecture.
