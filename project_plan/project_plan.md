## Project Scope and Learning Goals

The module is intended to help beginners move from little knowledge of
AI to a basic understanding of rule-based AI systems.

### Target Learners

First-year university students from any major who are new to computer
science. They are expected to know how to use a computer and have
secondary-school mathematics knowledge. No programming experience or
extensive AI experience is assumed.

### Learning Goals

After using the materials, a beginner should be able to:

1.  Explain what software is and how source code becomes a running
    program.
2.  Read short pseudocode or Python using variables, conditions, and
    loops.
3.  Explain symbolic AI and how it differs from machine learning.
4.  Represent simple knowledge as facts, rules, and logical statements
    using AND, OR, NOT, and IF-THEN.
5.  Trace forward and backward chaining on a small set of rules.
6.  Apply breadth-first and depth-first search to a small problem and
    compare the results.
7.  Evaluate when symbolic AI is a good or poor choice for a task.

## How We Study the Content

-   The course materials and references are reviewed by the person
    responsible for each topic.
-   At the Monday meeting, each topic owner explains their topic to the
    team in three minutes. If the explanation is not clear, the topic
    needs more work.
-   Team members ask questions and give feedback when something is
    unclear.
-   Another member reviews each topic to check that it is accurate and
    easy to understand.

Every piece of content goes from draft to peer review and quality check.
It is then checked in Markdown before being turned into a guide, slide,
or video.

## How Markdown Is Developed and Checked

1.  Draft the topic using the shared template.
2.  Ask another member to review the draft for correct definitions,
    beginner-friendly explanations, activities, source citations,
    images, and links.
3.  The Quality Lead checks what was reviewed and records changes in the
    review log.
4.  The topic owner fixes any problems.
5.  Only checked content moves into the study guide, slides, or videos.

## How We Use GitHub

-   Raphael creates the repository and adds every group member as a
    collaborator.
-   Each member commits their own work using clear commit messages.
-   Larger changes need review from other members.
-   Tasks are tracked by the team.
-   Personal logs and private information stay out of the public
    repository.
