# 1.6 Test Bank: File Systems and Storage

T6 and M6 are the same as in the *Dandroid's Logic Lab* Test Bank. Q1–Q3 are extra practice. Answers are at the bottom.

## Questions

**T6 (True or False).** A file path is like an address that tells the OS where a file is.

**M6 (choose ONE).** Which of these is a file path?

- A. C:\Users\Sam\Pictures\cat.jpg
- B. Ctrl + S
- C. 1,000 GB
- D. cat

**Q1.** Using the folder tree in Figure 1.6a, write the path to a file called `notes.txt` saved in Sam's Documents folder.

**Q2.** Give one reason to choose an HDD instead of an SSD.

**Q3.** A file was deleted by mistake yesterday. Explain why it might still be possible to get it back.

---

## Answer key

| No. | Answer | Why |
| --- | --- | --- |
| T6 | **True** | For example, `C:\Users\Sam\Pictures\cat.jpg` says: drive C, then the folders, then the file. |
| M6 | **A** | It gives the drive, the folders and the file name. B is a keyboard shortcut, C is a storage size, D is just a word. |
| Q1 | `C:\Users\Sam\Documents\notes.txt` | Follow the tree from C:\ down to Documents. |
| Q2 | Price | An HDD is cheaper for lots of space, so it suits big backups or video archives. |
| Q3 | Catalogue entry | Deleting usually removes only the file system's catalogue entry. The data stays on the drive until something overwrites it. |
