## Chapter 3 quick quiz

True or false? Decide first, then check the answers.

1. In Symbolic AI, knowledge usually comes from human-written facts and rules.
2. From "If P then Q" and "Q", we can safely conclude P.
3. Backward chaining starts with a goal.
4. A* always finds the best route, even if its heuristic overestimates.
5. A consistent rule-based system is always correct.
6. In Prolog, X is a variable.

**Answers**
1. True.
2. False: that's affirming the consequent.
3. True.
4. False: the heuristic must be admissible.
5. False: it can be consistently wrong.
6. True.
