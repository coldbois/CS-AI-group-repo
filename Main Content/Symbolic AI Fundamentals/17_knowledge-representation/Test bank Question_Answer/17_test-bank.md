# 3.2 Test Bank: Knowledge Representation

T18 and M18 are the same as in the *Dandroid's Logic Lab* Test Bank. Q1–Q3 are extra practice. Answers are at the bottom.

## Questions

**T18 (True or False).** In the triple (Mina, studies, Biology), the word "studies" links Mina to Biology.

**M18 (choose ONE).** In the triple (Kai, attends, North_College), what is "attends"?

- A. The subject
- B. The predicate (the link)
- C. The object
- D. A number

**Q1.** Using Figure 3.2b, which city is Mina's university in? Write the path of arrows. *(slide 36)*

**Q2.** Write in logic: "Every dog is an animal" and "Rex is a dog". What can be concluded?

**Q3.** Which representation would you use for "the usual steps of borrowing a library book"? Why?

---

## Answer key

| No. | Answer | Why |
| --- | --- | --- |
| T18 | **True** | A triple is subject → link (predicate) → object. |
| M18 | **B** | "attends" is the labelled arrow that links them. Kai is the subject, North_College the object, and it is a word, not a number. |
| Q1 | Beijing | Mina → attends → University_A → located_in → Beijing. |
| Q2 | ∀x Dog(x) → Animal(x); Dog(Rex); so Animal(Rex). | Modus ponens with a "for all" rule. |
| Q3 | A script | It is a usual sequence of events (find book → take it to the desk → scan card → take it home → return by the date). |
