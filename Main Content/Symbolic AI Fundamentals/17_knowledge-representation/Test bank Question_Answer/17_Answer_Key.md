# Topic 17 — Answer Key

1. KR organises facts, concepts and relationships in a form an AI system can store, retrieve and use for reasoning.
2. An entity is the thing being described (for example, a student); an attribute is a property (for example, student number); a relationship links entities (for example, student attends college).
3. Propositional logic treats complete statements as true or false. First-order logic can describe individual objects, properties and relationships using variables and quantifiers.
4. `∀` means “for all”; `∃` means “there exists”.
5. The subject is the resource being described, the predicate names the relationship or property, and the object is the related resource or value.
6. An IF–THEN rule states what follows when conditions are met. A knowledge graph makes entities and their labelled relationships visible and connected.
7. A frame describes an object or concept through slots and values. A script describes a typical sequence of events.
8. An ontology defines concepts and relationships in a domain using a shared, formal vocabulary. A simple category list may show hierarchy but not the full meaning or constraints of relationships.
9. `(Nora, attends, East_College)`.
10. It can conclude that Nora may borrow books, provided the rule and fact are accepted as true in the system and no additional condition blocks borrowing.
11. A frame is a reasonable choice because the system is describing one object through a set of attributes. A structured database record could also be appropriate.
12. The knowledge may be missing, outdated, incorrect or contradictory. Correct inference cannot repair inaccurate premises by itself.

## Marking note

For questions 6–8 and 10–12, accept other answers when the explanation is logically sound and consistent with the Main Theory.
