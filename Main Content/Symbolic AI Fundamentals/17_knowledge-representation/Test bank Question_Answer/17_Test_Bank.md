# Topic 17 — Test Bank

Answer the questions using the Main Theory file. Questions include recall, explanation and application.

## A. Short answer

1. What is knowledge representation, and why does an AI system use it?
2. Define an entity, an attribute and a relationship. Give one example of each.
3. What is the difference between propositional logic and first-order logic?
4. What do the symbols `∀` and `∃` mean?
5. What are the subject, predicate and object in an RDF triple?

## B. Explain or compare

6. Compare an IF–THEN rule with a knowledge graph. What type of information is each good at showing?
7. Explain the difference between a frame and a script.
8. What is an ontology, and how is it more than a simple list of categories?

## C. Apply the idea

9. Represent “Nora attends East College” as an RDF-style triple.
10. A system stores the rule “If a person is a library member, they may borrow books.” It also stores “Nora is a library member.” What can it conclude? State the assumptions.
11. A system needs to store a phone's model, storage size and operating system. Which representation from this topic would be a reasonable choice? Explain.
12. Give one reason why a knowledge base may produce an unreliable answer even when the reasoning procedure works correctly.
