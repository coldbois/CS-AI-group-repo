# Topic 17 — References and AI Usage

## References

1. Stanford Encyclopedia of Philosophy. **“Logic-Based Artificial Intelligence.”** Useful background on logic-based AI, knowledge representation and reasoning. https://plato.stanford.edu/entries/logic-ai/
2. World Wide Web Consortium (W3C). **“RDF 1.1 Primer.”** Defines RDF statements as subject–predicate–object triples and explains the graph data model. https://www.w3.org/TR/rdf-primer/
3. World Wide Web Consortium (W3C). **“OWL 2 Web Ontology Language — Document Overview.”** Explains OWL ontologies and their relationship to RDF. https://www.w3.org/TR/owl-overview/
4. World Wide Web Consortium (W3C). **“OWL 2 Quick Reference Guide.”** A reference for classes, properties, individuals and data values. https://www.w3.org/TR/owl2-quick-reference/

## What each source supports

- Use the Stanford entry for the wider role of logic and knowledge representation in AI.
- Use the W3C RDF Primer for the triple and graph explanation.
- Use the OWL documents for the ontology section. Avoid describing RDF and OWL as the same thing.
