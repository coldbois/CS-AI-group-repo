## Section B — Multiple Choice (7 questions)

1. Which option best describes Symbolic AI?
   - A. Learning only from large datasets
   - B. Representing knowledge explicitly and reasoning with symbols and rules
   - C. Generating random outputs
   - D. Storing files without processing them
2. What is a fact in a symbolic knowledge base?
   - A. A condition that must be tested
   - B. A stored piece of represented information
   - C. A user-interface button
   - D. A model-training epoch
3. What is the main role of an inference engine?
   - A. Draw the user interface
   - B. Store photographs
   - C. Apply reasoning procedures to facts and rules
   - D. Collect keyboard input only
4. Which reasoning strategy starts with known facts?
   - A. Backward chaining
   - B. Forward chaining
   - C. Random search
   - D. Image segmentation
5. Which strategy starts with a goal or query?
   - A. Backward chaining
   - B. Forward chaining
   - C. Data cleaning
   - D. Clustering
6. Which event is commonly associated with the formal emergence of AI as a research field?
   - A. The 1956 Dartmouth Summer Research Project
   - B. The launch of the World Wide Web
   - C. The creation of the first smartphone
   - D. The release of Python 3
7. Which is an example of a structured knowledge representation?
   - A. An unlabelled audio waveform
   - B. A knowledge graph of entities and relationships
   - C. A random video file
   - D. A folder of unsorted screenshots
