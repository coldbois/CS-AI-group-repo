## Section B — Multiple Choice (7 questions)

1. Which is an advantage of explicit rules?
   - A. They guarantee fairness
   - B. They can make reasoning paths easier to inspect
   - C. They eliminate the need to validate data
   - D. They solve every unfamiliar case
2. What does consistency mean in a deterministic rule system?
   - A. Its rules are always morally correct
   - B. It applies the same defined rules in the same way to equivalent cases
   - C. It learns a new rule after every input
   - D. It never needs maintenance
3. What is the knowledge-acquisition bottleneck?
   - A. The difficulty of collecting and encoding specialist knowledge
   - B. A slow monitor
   - C. The lack of programming languages
   - D. The process of deleting old files
4. Why can simple deterministic rules struggle with uncertainty?
   - A. They cannot store any facts
   - B. They are easiest to apply when conditions are crisp and known
   - C. They always require image data
   - D. They cannot display output
5. Which is a common maintenance challenge?
   - A. Rules can interact and create exceptions or conflicts
   - B. Every rule is automatically deleted
   - C. The knowledge base never changes
   - D. All outputs are random
6. Which task is least naturally suited to a small hand-written rule set alone?
   - A. Checking a fixed policy condition
   - B. Verifying a structured form
   - C. Recognizing objects directly from raw photographs
   - D. Applying a defined eligibility threshold
7. What is the key difference between consistency and correctness?
   - A. There is no difference
   - B. Consistency means repeated rule application; correctness means the rules and data fit the task
   - C. Correctness means the same output every time
   - D. Consistency means a system uses a neural network
