# Chapter 3 Test Bank — Questions

**Chapter:** Putting Software and Symbolic AI Together

Answer all questions. True/False questions require one answer. Multiple-choice questions have one best answer. For open-ended questions, provide developed reasoning and examples; aim for more than 100 words or equivalent reasoning through a diagram or worked steps.

## Section A — True / False (6 questions)

1. Software can provide the interface and application logic around a symbolic reasoning component.  
   Answer: True / False
2. Every Python program that contains an if statement is automatically a complete expert system.  
   Answer: True / False
3. In Prolog, facts, rules and queries are basic constructs.  
   Answer: True / False
4. In Prolog, a variable is conventionally written with a lowercase first letter.  
   Answer: True / False
5. In Prolog, the operator `:-` separates a rule head from its body.  
   Answer: True / False
6. The Prolog query `grandparent(john, alice)` can succeed if the facts and rule establish that relationship.  
   Answer: True / False
