# Topic 18 — Answer Key

1. Reasoning is using facts and rules to reach conclusions.
2. Deduction applies rules to cases; induction generalises from observations; abduction suggests a possible explanation for an observation.
3. Inference is deriving a statement from premises or known facts.
4. It matches rules to facts and applies them to derive new conclusions.
5. Any four of: knowledge base, inference engine, working memory, user interface, explanation facility, knowledge acquisition/maintenance process.
6. Example: If a file is saved, it appears in the folder. The file was saved. Therefore, it appears in the folder. The premises and conditional rule must be accepted for the conclusion to follow.
7. Q may be true for another reason. The argument would affirm the consequent, which is not a valid inference form.
8. Forward chaining begins with facts and derives conclusions. Backward chaining begins with a goal and checks the facts needed to support it.
9. It helps users inspect which facts and rules led to the result. It supports checking, but does not guarantee the result is correct.
10. The system can infer `may_borrow`, assuming the rule and fact apply and no additional condition blocks borrowing.
11. No. It can only conclude that the stated reason for the job not starting is absent. Other problems may stop the job from starting.
12. It should apply a defined conflict-resolution policy, ask for more information or report that the rules conflict. It should not choose arbitrarily.
