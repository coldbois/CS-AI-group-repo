## Chapter 2 quick quiz

True or false? Decide first, then check the answers.

1. An interpreter translates and runs a program line by line.
2. A logic error stops the program from starting.
3. Binary search works on any list, sorted or not.
4. A queue serves the oldest item first.
5. Two rows in a table may share the same primary key.
6. In Agile, teams get user feedback after each sprint.

**Answers**
1. True.
2. False: that's a syntax error; a logic error gives wrong answers.
3. False: the list must be sorted.
4. True.
5. False: a primary key must be unique.
6. True.
