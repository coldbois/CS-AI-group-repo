# Topic 11 — Learner Activities

These activities reinforce **Computer Programming**. Complete them after reading the Main Theory. Each activity includes an expected outcome so learners can check their understanding.

## Activity 1 — Identify a logic error

A program compiles and runs, but returns the wrong result for an input. What type of error is this?

**Expected outcome / answer guide:**
A logic error.

## Activity 2 — Design tests

For the leap-year rule, choose one leap year, one non-leap year and one century edge case.

**Expected outcome / answer guide:**
Examples: 2024 (leap); 2023 (not leap); 1900 (not leap because not divisible by 400).

## Reflection

In two or three sentences, explain one way computer programming connects to another topic in this course. A strong answer names the other topic and describes a specific connection.
