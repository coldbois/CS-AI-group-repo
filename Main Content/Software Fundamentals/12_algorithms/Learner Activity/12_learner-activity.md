# Topic 12 — Learner Activities

These activities reinforce **Algorithms**. Complete them after reading the Main Theory. Each activity includes an expected outcome so learners can check their understanding.

## Activity 1 — Choose a search

A list is sorted and supports indexed access. Which search can repeatedly halve the search range?

**Expected outcome / answer guide:**
Binary search.

## Activity 2 — Compare growth

For large n, which generally grows more slowly: O(n log n) or O(n²)?

**Expected outcome / answer guide:**
O(n log n), so it is usually more efficient at sufficiently large input sizes.

In two or three sentences, explain one way algorithms connects to another topic in this course. A strong answer names the other topic and describes a specific connection.
