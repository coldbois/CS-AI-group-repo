**Claims that need a second look when you check sources**
- Section 7.3 says the standard version of Python compiles source code to bytecode and then runs it. Confirm against the Python documentation.
- Section 7.1 says different CPU families have different machine code, with PC and phone chips given as an example. Find a source and name the instruction sets precisely if you want to.
- Sections 10.2 and 10.3 give *simplified* summaries of MIT and GPL, including "generally no obligation to publish if you do not distribute". Compare each statement with the licence text and the FSF's explanations before keeping the wording.
- Section 11.3 says `24.04` means April 2024 for a well-known Linux distribution. Check the distribution's own release naming page.
- Section 5.3 says some systems, like ChromeOS, are built around a browser. Check the vendor documentation.
