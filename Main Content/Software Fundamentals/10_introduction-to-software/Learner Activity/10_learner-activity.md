# Try it: Software Safari (2.2)

**Time:** 15 min · **Group:** solo · **You need:** your phone or laptop · Study Guide pp. 65–66

**Goal:** classify real software and judge its quality like a software reviewer.

## Prepare

Open your phone's app list or your laptop's Start menu (or Launchpad on a Mac).

## Steps

1. Pick **8 pieces of software** you use. Sort them into system, application, programming and middleware.
2. Find one that is **open source** (hint: Firefox, VLC, Linux, Python).
3. Pick your favourite app. Give it 1–5 stars for each quality in the table below, with one piece of evidence.
4. Which quality is weakest? Suggest one fix.

## Reflect

- Why was "maintainable" hard to judge as a user?
- Was any app hard to sort into one type?

## Check it: expected results

- Most of your list will be **application** software. The OS and drivers are **system** software working quietly underneath. Unless you code, you probably have no programming software yet (a text editor such as VS Code would count).
- **Maintainable** means other developers can understand and update the code. Users can't see the code, so you can only guess, for example from how often the app gets updates.
- Some apps fit two types. That's fine if you explain your choice (a web browser is an application, but it also runs other people's code).
- Open-source examples: Firefox, VLC, LibreOffice, Linux, Python.
