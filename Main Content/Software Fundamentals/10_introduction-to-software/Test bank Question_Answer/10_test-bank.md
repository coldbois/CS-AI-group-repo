# 2.2 Test Bank: Introduction to Software

T10 and M10 are the same as in the *Dandroid's Logic Lab* Test Bank. Q1–Q3 are extra practice. Answers are at the bottom.

## Questions

**T10 (True or False).** A web browser is an example of application software.

**M10 (choose ONE).** What does a compiler do?

- A. Translates the whole program into machine code before it runs
- B. Draws pictures on the screen
- C. Stores your files
- D. Connects to Wi-Fi

**Q1.** Put in order: machine code, running process, source code, compiler.

**Q2.** Sort into system or application software: a printer driver, a photo editor, the Windows OS, a music app.

**Q3 (True or False).** An interpreter translates and runs a program line by line. *(Chapter 2 quick quiz)*

---

## Answer key

| No. | Answer | Why |
| --- | --- | --- |
| T10 | **True** | Application software helps you do a task. System software (like the OS) runs the computer. |
| M10 | **A** | It turns source code into 0s and 1s the CPU understands. Drawing (B), storing files (C) and Wi-Fi (D) are done by other software. |
| Q1 | source code → compiler → machine code → running process | Figure 2.2b. |
| Q2 | System: printer driver, Windows OS. Application: photo editor, music app. | System software runs the computer; applications help you do tasks. |
| Q3 | **True** | A compiler translates the whole program first instead. |
