## Meet Dandroid, your lab partner

Dandroid is a brand-new robot. It has a body, but it doesn't know how that body works, how to follow instructions or how to think. Your job is to teach it, one mission at a time.

![The route through the module](images/0_route.png)

We build from the bottom up: the operating system runs the machine, software gives it instructions, and Symbolic AI lets it reason. By the end, Dandroid solves the wolf–goat–cabbage river puzzle using all three layers.

## Who this module is for

**Intended learners:** first-year university students from any major who are new to computer science.

**Before you start (prerequisites):** you need to be able to use a computer or phone, read simple English and do basic arithmetic. **No programming or AI experience is needed.** Where code appears, we explain it line by line, and every coding activity can also be done on paper.

## What you will learn

By the end of this module you will be able to:

**Operating Systems (Chapter 1)**
1. Explain what an operating system does and how a computer boots.
2. Trace processes, scheduling and memory.
3. Apply security ideas and read basic C.

**Software (Chapter 2)**

4. Classify software and write simple programs.
5. Compare algorithms and data structures.
6. Query a database and describe how teams build software.

**Symbolic AI (Chapter 3)**

7. Represent knowledge as facts, rules and graphs.
8. Trace reasoning, search and planning, including forward and backward chaining.
9. Judge when to use Symbolic AI and build a small rule-based app.

These are the same outcomes as the Study Guide (p. 5) and the teaching slides (slide 4).

## How each topic works

Every topic (01 to 21, the same as Study Guide sections 1.1 to 3.6) has its own folder with five parts:

| Folder | What's in it |
| --- | --- |
| Main Theory | the lesson: a **Mission** from Dandroid, explanations with pictures, a worked example, **Bug alerts** (common mistakes), **Dandroid's tips**, *Check yourself* questions with answers, a **Remember** box, links to watch and references |
| Diagrams and Pictures | the pictures for the lesson. Most are taken from our Study Guide and slides, so you see the same pictures everywhere |
| Learner Activity | the **Try it** activity: goal, what to prepare, steps, a table to record results, questions to think about and the expected answers. Some topics also have a `code` folder |
| Test bank Question_Answer | practice questions with an answer key. Questions numbered T, M or O are the same as in the *Dandroid's Logic Lab* Test Bank |
| Teammate_review | the review of this topic by a teammate who did not write it |

Inside every lesson the order is the same: **mission, predict, explain, try, check, remember.** Try to guess an answer before you look. Wrong guesses teach the most!

Sections called "Going further (optional)" go beyond the module. You don't need them for the Test Bank.
## How to run the code

All the code is short and has its expected output written next to it, so you can also just read it.

| Language | Where | How to run it | No install? |
| --- | --- | --- | --- |
| Python 3 | topics 11, 12, 13, 14, 18, 19, 21 | `python file_name.py` in a terminal, inside the topic's `Learner Activity/code` folder | paste into any online Python editor, e.g. the shell on python.org |
| C | topic 08 | `gcc hello.c -o hello`, then `./hello` (`hello.exe` on Windows) | OnlineGDB (onlinegdb.com/online_c_compiler) |
| Prolog | topic 21 | paste `family.pl` into a new Program at swish.swi-prolog.org | SWISH runs in the browser |
| SQL | topic 14 | `books_starter.py` builds the table with Python's built-in `sqlite3` | SQLite Online (sqliteonline.com) |

The Python files use only the standard library: nothing to install with pip. Every online activity has a paper or screenshot fallback in its *Check it* section.
