# Resource Map

This map shows where each Markdown topic is used in our other learning resources. It updates the Stage 2 mapping. The resources differ in detail on purpose: the **slides** support classroom teaching, the **video** explains and demonstrates, and the **Study Guide** supports independent learning. The underlying definitions, examples and answers are the same; the last section lists the checks we made.

- **Folder numbers:** topic folders 01–08 are sections 1.1–1.8, 09–15 are 2.1–2.7, 16–21 are 3.1–3.6
- **Study Guide** = *Dandroid's Logic Lab: Study Guide V1.0* (page numbers)
- **Test Bank** = *Dandroid's Logic Lab Test Bank* (T = true/false, M = multiple choice, O = open-ended)
- **Slides** = *DanDDisciples_Stage2_PPT_V1* (slide numbers)
- **Video** = mini-lecture video *How does an expert system reach and explain a conclusion?* (`DanD_Disciples_MiniLecture_ExpertSystem.mp4`)
- "not used" means the topic was **not selected** for that resource.

## Consistency checks we made

We compared every Markdown topic with the Study Guide, the Test Bank, the slides and the video. What we checked and what we changed:

| Check | Result |
| --- | --- |
| Definitions and glossary terms | Markdown definitions now use the Study Guide wording; the [Glossary](Glossary.md) contains every Study Guide glossary term. |
| Worked examples and numbers | All shared numbers were recalculated (FCFS/RR averages, page faults, binary-search checks, SQL results, river plan) and match all four resources. Code examples were run to confirm their output. |
| Test Bank answers | All 57 Test Bank questions appear in the topic test banks with the same numbers and answers. |
| Figures | Figures now come from the Study Guide and slides (page or slide number in each caption). External hotlinked images were removed. |
| GPA rule | Changed: an old team diagram said "GPA ≥ 3.0"; Markdown, guide, slides and Test Bank now all use "GPA ≥ 3.5 → academic_ok" for the scholarship rule. (The 3.6 Python example is a separate two-criteria admission rule and keeps its 3.0 threshold, as in the guide.) |
| Boot steps | The slides show 5 boot steps and the guide shows 7. Not a contradiction: 1.2 now explains that the slides group the same 7 steps into 5. |
| Battery Detective fact names | The Study Guide model answer uses `many_background_apps` with five chained rules; Test Bank O7 uses `many_apps_open` with three rules. The advice is the same; 3.3's activity now explains the link. Recommended for the next Test Bank version: use the guide's fact name. |
| Laptop example | 3.3 now includes the mini-lecture video's six laptop rules, its forward/backward traces, the WHY/HOW explanations and its check question (answer B), so the video and Markdown match. |
| File path on slide 14 | Slide 14 shows `C:\Users\Sam\cat.jpg`; the guide and Test Bank use `...\Sam\Pictures\...`. Both are valid paths; no change needed. |
